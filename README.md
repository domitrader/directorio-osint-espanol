# OSINT Hub en Español 🔍

Directorio profesional, rápido y claro de herramientas de Inteligencia de Fuentes Abiertas (OSINT) totalmente en español.

## Características

- ⚡ **Rápido y táctico**: Búsqueda instantánea en tiempo real sin recargas con soporte de atajo de teclado (`/`).
- ☀️ **Diseño Claro y Agradable**: Interfaz limpia, moderna y profesional pensada para no cansar la vista en jornadas de investigación.
- 💡 **Tips Tácticos OSINT**: Cada herramienta incluye una explicación concisa y un caso de uso práctico específico.
- 🎯 **Filtros por Coste**: Clasificación instantánea en *Gratis*, *Freemium*, *De pago* y *Open Source*.
- ⭐ **Favoritos Persistentes**: Guarda tus herramientas de cabecera con guardado local en el navegador.
- 🚀 **Lanzador Directo de Consultas**: Módulo de búsqueda rápida para usernames, IPs, dominios, correos y Google Dorks.
- 🌐 **Listo para Vercel**: 100% estático, ultra-ligero y preparado para despliegue en CDN global.

## Despliegue en Vercel

### Opción 1: Conexión Automática con GitHub (Recomendada)
1. Importa este repositorio desde el panel de [Vercel](https://vercel.com/new).
2. Presiona **Deploy**. No requiere comandos de compilación.

### Opción 2: Vercel CLI
```bash
npx vercel deploy --prod
```
