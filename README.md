# OSINT Hub en Español 🔍

Directorio profesional, táctico y modular de herramientas de Inteligencia de Fuentes Abiertas (OSINT) 100% en español. Desarrollado con el estándar de máxima calidad **Gauntlet Loop**.

## 🚀 Características Principales

- ⚡ **85 Herramientas Tácticas Verificadas**: Sin *placeholders*, clasificadas por categoría, coste (*Gratis*, *Freemium*, *De pago*, *Open Source*), nivel técnico y nivel OPSEC (*Seguro / Pasivo*, *Activo*, etc.).
- 🔄 **Workflows Tácticos Paso a Paso**: Metodologías periciales guiadas para investigación de personas, auditoría de dominios e infraestructura, verificación forense de imágenes (cronolocalización) y trazabilidad blockchain.
- ⚡ **Constructor Interactivo de Google Dorks**: Plantillas forenses listas para descubrir documentos confidenciales, credenciales expuestas, directorios abiertos y copias de seguridad.
- 📁 **Exportador de Expedientes en Markdown**: Genera y copia al portapapeles el kit de investigación seleccionado con un solo clic.
- 🎯 **Lanzador Directo**: Módulo de búsqueda rápida con atajos de teclado (`/` o `Ctrl+K`) y consulta directa en Shodan, Censys, WhatsMyName, VirusTotal y Epieos.
- 🤖 **Skill Gauntlet Loop Integrado**: Incluye la especificación técnica del [Gestor de Proyectos con Gauntlet Loop](.agents/skills/project-gauntlet-loop/SKILL.md) guardada en el repositorio.
- 🌐 **Optimizado para Vercel**: Arquitectura modular en JavaScript ESM puro, CSS estructurado y ultra-ligero para despliegue global instantáneo.
